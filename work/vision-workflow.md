# 看图的工作流

有人发图让你看，**不要直接把整张图丢给 `qqbot_describe_image` 问一句就完事**。
这套流程是本机那套识图体系实测出来的，照它做才准。

## 为什么不能整图直接问（一个真实例子）

一张 2560×1578（4 MP）的游戏截图，整图问「这图里是什么」，模型回答：

> 「金色长发，兜帽上有红色狐狸耳，**银色配红色的露脐装**……」

**错在哪**：角色外层是**红色无袖披风**、里面是**银灰色胸衣**，两件独立的衣服被模型
合并成了"银色配红色的露脐装"，还凭空多出个"露脐"。

**原因**：4 MP 的图被缩到模型能吃的尺寸后，红披风和银灰胸衣**重叠成了一个色块**。

**同一张图，裁出上半身、放大 3 倍之后再问**，模型立刻说对了：

> 「最外层是红色的兜帽/披风，无袖、敞开；里面一层是**银灰色、金属质感、带叶片状花纹的胸衣**；这块区域没有露出腹部皮肤。」

**差别就在"有没有放大"。**

## 四步流程

### 第 0 步：先量尺寸（不要跳过）

```bash
python E:\dsh-qqbot\tools\imgtool.py size "<图片路径>"
```

输出会告诉你 `megapixels` 和一个 `advice`：

- **小于 2 MP** → 尺寸不大，整图问通常够用
- **大于 2 MP** → **必须先裁图**，否则细节必丢

### 第 1 步：能算的先算（绝不问模型）

**尺寸、颜色这类问题，算法几毫秒就能算准，而模型会看错。** 实测过：两个模型异口同声说
某颗扣子是金色，`PIL` 取色证明是深蓝近黑（`#272948` 占 62%）。

```bash
# 整个区域的主色
python E:\dsh-qqbot\tools\imgtool.py color "<图片路径>" --top 6

# 指定区域的主色（问"这块是什么颜色"之前先跑这个）
python E:\dsh-qqbot\tools\imgtool.py color "<图片路径>" --region 1100,300,1500,900 --top 5
```

**判据**：只要问题能用"数出来、量出来、取色"回答，就先跑脚本。脚本给了数字之后，
模型的话只用来补充**形状、语义、关系**这类算不出来的东西。

### 第 2 步：裁出目标区域并放大（看细节必备）

```bash
python E:\dsh-qqbot\tools\imgtool.py crop "<图片路径>" --region x1,y1,x2,y2 --out "<输出路径>" --scale 3
```

- `--region` 是**原图像素坐标** `x1,y1,x2,y2`
- `--scale 3` 放大 3 倍（小目标可以到 6~8 倍）
- **不知道目标在哪** → 先用 `grid` 切成 3×3 逐块看：

```bash
python E:\dsh-qqbot\tools\imgtool.py grid "<图片路径>" --cols 3 --rows 3
```

### 第 3 步：对**裁出来的那块**提问（不是整图）

```
qqbot_describe_image(image="<第2步输出的裁图路径>", prompt="<具体的问题>")
```

**问法要点**：

| 要问的 | 该怎么问 |
| --- | --- |
| 颜色 | 先跑 `color --region`，然后问"这块是什么部件" |
| 个数 | 「数一下这块区域里有几个X」——**指清单一品类** |
| 相近部件 | **分开问**：「最外层是什么」「里面那层是什么」，别问"这身衣服是什么" |
| 位置关系 | 「A 在 B 的上面还是下面」 |

**问法修不了看错，但能修用词**：形状认错、左右搞反这类，换问法没用，只能靠**放大**。

## 什么该标「存疑」

**不确定的宁可不说，也不要编一个听起来合理的答案。** 编错了比没说是更糟的事。

必须标存疑的情形：

- 模型说「看不清 / 无法判断」
- **两个模型（或同一模型两次）说法冲突** —— 比如一个说"银灰"一个说"白色"
- 颜色落在高光/阴影里（金属反光、逆光）—— 这类**模型和人眼都不可靠**，以取色为准
- 目标小于整图 5%（小扣子、小字）—— 没放大过就不要下结论

写在回答里的样子：「围巾颜色我看不太准，可能灰蓝或者银灰」——**这样比说错强**。

---

## 一句话版

1. **先量尺寸**（大图必须裁）
2. **能算的算**（颜色/个数用脚本，别问模型）
3. **看细节先裁出放大**（这是最关键的一条）
4. **分开问相近部件**（外层的问外层，里面的问里面）
5. **拿不准就标存疑**（不要编）
