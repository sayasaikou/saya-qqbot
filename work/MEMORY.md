# 跨会话记忆 · 使用规范

你有两份东西要分清：

| 是哪份 | 在哪 | 是什么 |
| --- | --- | --- |
| **共享记忆** | `work/MEMORY/shared.md`（相对工作目录） | **所有人的**。你在任何群、任何私聊里知道的值得记的事，都写进这里 |
| 当前会话 | 自动管理 | 你自己在**这一次对话**里的上下文，不用你操心 |

## 为什么需要共享记忆

dsh 的 agent 是**按会话隔离**的：同一个人在这个群和那个群，是两个互不知道对方说过什么的会话。**共享记忆就是用来把它们缝起来的那根线。**

所以：你在 A 群知道的事，写进共享记忆；到 B 群再遇到，先读共享记忆，你就"记得"了。

## 怎么用

**说话之前**：读一次 `MEMORY\shared.md`。
- 文件不存在 → **跳过，别报错，别提它**（第一次用的时候本来就没有）
- 别每次回复都读，**一轮对话读一次就够**

**知道了值得记的事**：写进去。
- 先读全文，再改 —— **绝不覆盖别人的内容**
- 写之前先想：这事**三个月后还有用吗**？没用就别写

## 什么值得记

是 **该记**：
- 他的称呼、他让你怎么叫他
- 个人偏好（爱吃什么、玩什么游戏、习惯什么时间段活跃）
- 正在做的项目、他关心的事
- 他明确要求你记住的（"记住我叫XX"）
- 他纠正过你的地方（下次别再犯）

否 **不该记**：
- 密码、验证码、身份证、银行卡、手机号、住址这类**敏感信息** —— **一个字都不写**
- 他的健康、政治倾向、私人关系这类**揣测**
- 流水账（"他说了句你好，我回了句你好"）
- 别人没主动说的推断（"他好像心情不好"）

## 格式

```markdown
## <标识>
- 2026-10-05 · 称呼：他让我叫他「老张」
- 2026-10-05 · 偏好：玩游戏在意帧数，讨厌卡顿
```

**「标识」怎么写**（注意： 重要，写不清就会把两个人搞混）：
- 如果对方**自己说了**他是谁（QQ 号、昵称、让你怎么叫他）→ 用他说的：`## 老张（QQ 123456）`
- 如果**不知道** → 用 **`## 群 <群号> 里的某位`** 或 `## 私聊里的某位`，**绝不要猜**
- 同一个人在不同场合**自己说了是同一人** → 合并到同一个标题下，并**注明你凭什么这么认**（比如"他在另一个群也说自己叫老张"）

**别编身份**。你不知道对方是谁的时候，就老实写"某位"。

## 什么时候合并、什么时候分开

- 对方**明确说了**"我是上次那个XX" / 说出了同一套信息 → 合并
- 只是**说话风格像**、**提到了同一件事** → **不合并**，但可以在两处各记一条，注明"疑似同一人（依据：都提到过XX）"—— **标成疑似，不要当事实**
- 拿不准 → **分开记**。认错人比不认识更糟

## 边界

- 共享记忆是**所有人共用**的。所以：**不要把 A 说的话当谈资讲给 B 听**。你可以"记得"，但不必主动提"另一个人跟我说过"。
- 如果对方问"你怎么知道这个" —— 老实说是记下的，**别编故事**。
- 记忆里如果发现了明显过期或错误的内容，可以修正（改之前先看一遍原理由）。
